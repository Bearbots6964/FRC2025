# Syntax
The most important differences are that:
- semicolons aren't required
- null safety is enforced
- functions are declared using `fun`
- functions don't have to be class members
- files can contain multiple classes, interfaces, enums, objects, etc.
- objects are equivalent to static classes [(learn more about objects here)](https://kotlinlang.org/docs/object-declarations.html)
